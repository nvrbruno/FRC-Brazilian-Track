# FRC Brazilian Track

Aplicativo mobile desenvolvido com React Native e Expo, com o objetivo de apresentar informações sobre equipes brasileiras de robótica da FIRST Robotics Competition (FRC).

## Sobre o projeto

O FRC Brazilian Track será um aplicativo que utilizará a API da FIRST para consultar e exibir dados sobre competições de robótica no Brasil.

A proposta é facilitar o acesso a informações sobre times brasileiros, eventos e resultados das competições, reunindo esses dados em um único aplicativo mobile.

## Funcionalidades

* Consulta de equipes brasileiras da FRC.
* Visualização de informações sobre os times.
* Consulta de eventos e competições.
* Exibição de resultados e dados das competições.
* Organização das informações de robótica em uma interface mobile.

## Tecnologias utilizadas

* React Native
* Expo
* TypeScript
* API da FIRST Robotics Competition

## Objetivo

Desenvolver um aplicativo mobile que facilite o acompanhamento das equipes brasileiras de robótica e das competições da FIRST, permitindo que os usuários consultem informações de forma prática e acessível.
